# Legal Metrology — Online Verification System

SIH 2026 Problem Statement 26036 — frontend prototype.

## Tech
- React + Vite
- Tailwind CSS
- React Router
- Lucide React icons

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Demo
